Author: Arjun D | Finance Head | FP&A | IFRS | 10+ years
LinkedIn: https://linkedin.com/in/arjundayalan

## What This Does

Python toolkit automating three FP&A workflows done manually in Excel:

- variance_analysis.py: Budget vs Actual P&L with auto-commentary and waterfall charts
- working_capital.py: DSO / DPO / DIO / CCC trends across periods  
- cash_flow_forecast.py: 13-week rolling direct cash flow forecast with stress scenarios

## Quick Start

pip install pandas matplotlib numpy
python variance_analysis.py
python working_capital.py
python cash_flow_forecast.py

## Real-World Context

At Cotton World Group (Rs600Cr+ conglomerate, 6 entities) drove DSO from 90 to 30 days and achieved near-zero net debt. Monthly CFO-pack prep time cut by 70%.

At Ciel Et Terre Solar (India arm of France-HQ floating solar company) deployed cash flow model giving the France CFO real-time INR visibility across IST/CET time zones.
